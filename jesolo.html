Co vzít s sebou

  • Opalovací krém SPF 50 — UV index bývá 6–8, velmi vysoký od 11 do 15 h
  • Lehké oblečení — přes den kolem 25–28 °C, večer pokles k 17 °C
  • Lehká mikina / svetr — večerní procházky po lungomare
  • Sluneční brýle + klobouk — celodenní pobyt na pláži
  • Adaptér IT — typ L (třípinový), nabíječky s USB-C fungují bez

Zdroje: open-meteo.com — Ensemble API (GEFS 0,5° + ECMWF IFS 0,25°), Forecast API (do 16 dnů), Marine API (teplota moře) a Archive API (ERA5) pro klimatologii 2014–2025. Pravděpodobnost = podíl členů ensemblu, u kterých jev nastal. Rozptyl teploty ukazuje shodu modelů — nižší = vyšší jistota.
